# Máquina+ — MVP

Primeira versão do marketplace de máquinas novas e usadas.

## Arquivos
- index.html — estrutura da página
- style.css — identidade visual e responsividade
- script.js — busca, filtros e protótipos de formulários

## Como testar no computador
1. Extraia os arquivos.
2. Abra `index.html` no navegador.
3. Teste a busca, categorias e botões "Tenho interesse".

## Próxima etapa
Conectar os formulários ao Google Forms/Google Sheets e trocar os dados de exemplo pelas máquinas reais.

## Importante
Esta versão é um MVP visual/funcional. Ainda não possui:
- login de vendedores;
- banco de dados;
- pagamento online;
- cadastro automático de anúncios;
- comissão automática;
- painel administrativo;
- integração real com WhatsApp/CRM.

Esses itens entram na fase 2.
